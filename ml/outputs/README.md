# Локальные результаты

Этот каталог объединяет результаты прогнозов, проверок и запусков интерфейса.
Прежняя корневая папка `outputs` перенесена сюда с сохранением содержимого.

Команды запускаются из каталога `ml`; пути вида `outputs/...` относятся к этой папке.
Сгенерированные CSV, журналы, снимки экрана и временные профили браузера остаются
на локальном компьютере и исключены из Git. В репозитории хранится только этот README.
