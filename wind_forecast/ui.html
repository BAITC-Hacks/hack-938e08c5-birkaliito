Формат входных данных

Погода: valid_time, wind_speed_10m, wind_speed_100m, wind_direction_100m, temperature_2m, surface_pressure. Время без часового пояса — Asia/Almaty. Единицы: м/с, градусы, °C, гПа. Необязательный actual_power (0–1) — только для оценки ошибки. Пример в шаблоне вымышленный.

CSV турбины из кейса загружается без изменения столбцов. Выберите ниже соответствующую турбину. Погода берётся из локального архива; для проверки доступны январь–февраль 2026.

Разделитель: запятая, точка с запятой или табуляция. Кодировка: UTF-8 или Windows-1251.
